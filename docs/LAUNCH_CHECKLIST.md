# Nova Studio launch checklist

## Product readiness
- [ ] Test image import, adjustments, undo/redo and export in current Chrome, Firefox and Safari.
- [ ] Test video import and timeline on supported devices.
- [ ] Test project save/restore after reload and malformed local project data.
- [ ] Verify AI features with a configured provider key and confirm costs/limits.
- [ ] Add a visible feedback path and monitored support contact.
- [ ] Replace demo artwork with real screenshots captured from the current app.

## Acquisition readiness
- [ ] Verify canonical URL, Open Graph preview, robots.txt and sitemap.xml.
- [ ] Register the site in Google Search Console and submit the sitemap.
- [ ] Publish a real tutorial and product walkthrough.
- [ ] Contact only relevant creators/studios and respect opt-outs.
- [ ] Launch on directories only after checking current submission rules.
- [ ] Do not buy followers, email lists, reviews or traffic.

## Conversion readiness
- [ ] Measure editor CTA clicks and first successful export.
- [ ] Add optional, explicit feedback/waitlist capture with a privacy notice and unsubscribe route before collecting emails.
- [ ] Add a real referral backend before promising rewards.
- [ ] Keep checkout disabled until provider approval and server-side verification are complete.

## Legal and operations
- [ ] Publish accurate Privacy, Terms, Refund/Cancellation and Contact pages.
- [ ] Verify business identity, tax and consumer obligations for India and target countries.
- [ ] Confirm hosting and AI provider terms allow commercial use.
- [ ] Add error monitoring, backups and a process for user data requests.
