## 2025-05-18 - Canvas 2D Path Batching & Luminance LUT Optimization
**Learning:** In HTML5 Canvas rendering loops, calling individual draw commands (`ctx.fillRect`) thousands of times per frame incurs extreme Canvas 2D API call overhead. Batching paths using `ctx.beginPath()`, `ctx.rect()`, and `ctx.fill()` collapses thousands of draw calls into a single context dispatch. Additionally, pre-computing tone deltas in a 65,281-element Float32Array (`toneDeltaLUT`) mapped to integer luminance `(red * 54 + green * 183 + blue * 19)` eliminates per-pixel floating-point math across millions of pixels.
**Action:** Always batch canvas path primitives (`ctx.rect`, `ctx.arc`) before filling or stroking, and use Float32Array LUTs for byte-range RGB integer calculations in per-pixel loops.
